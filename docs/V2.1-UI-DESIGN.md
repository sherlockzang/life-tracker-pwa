# Life Tracker V2.1 界面升级方案

状态：部分视觉方向已在 V2.1 实现，主要调整首页、登录页、行程标题和移动端导航；下方其余内容是后续设计目标，不代表均已实现或完成真机验收。实际线上状态以发布记录为准。原始交互构想见 [V2.1 静态预览](preview-v2.1.html)，其中全部为示例数据。

## 设计方向：每天都值得记录

保留已选择的蓝色品牌、iOS 式清晰布局和深浅主题，把复杂的表单体验整理为「今天、接下来、历史」三个可理解的层次。首页更像一个生活概览，行程是按当地日期排列的计划，交通详情同时表达计划与实际，不用彩色卡片堆叠信息。

## 页面设计

- **首页**：顶部显示日期、问候与同步状态；「今天」卡片呈现当前行程、下一项计划和快捷新增入口；下方时间线统一按时间排序。没有计划时展示空状态，不凭空生成记录。
- **行程**：顶部清楚显示目的地、日期与当地时区；横向日期条只负责切换日期。全天及住宿先于定时日程，入住、续住、退房和换酒店使用明确标签；跨日航班显示在实际归属日，卡内保留两端当地日期。
- **航班**：默认露出航司、航班号、出发／到达机场、当地时间和时长。实际航班数据单独标记来源与匹配时间；计划和实际不同则并列展示，不覆盖用户填写内容。编辑、撤销完成和重新匹配入口清晰可见；未来航班提示手动填写。
- **快速新增**：首屏选择消费、行程或随记；输入字段按必要程度分组，选填项显式标注。切换类型和关闭前保留草稿，并给出明确的保存或同步状态。
- **AI 入口**：将路线、摘要和整理功能放在相关场景，而非堆在首页。生成中、结果未保存和额度不足分别提示；结果必须能复制或保留，避免重复付费调用。
- **设置与同步**：Owner 后台仍由服务端权限控制；同步失败提供本机与云端对比、明确选择、导出副本和失败原因，不依赖颜色传达状态。

## 视觉与无障碍

主色继续使用 `#0A84FF`，深色保留纯黑背景及分层深灰，浅色保留低饱和背景与高对比文字。卡片尽量减少边框和装饰，统一 16px 圆角与 8px 间距节奏；正文建议不低于 15px，辅助说明不低于 13px，触控目标至少 44×44px。验证深浅主题对比、VoiceOver 标签、动态字号及减少动态效果设置。

## iPhone 和边界

优先验证 iPhone 17 Pro 主屏幕 PWA，顶部内容避开安全区与灵动岛，底部导航避开 Home 指示条和键盘；兼容 320px 窄屏、横屏及其他手机。不会以固定型号尺寸代替 `safe-area-inset`。复杂弹窗支持滚动、关闭和恢复焦点。

## 不改变的行为及验收

本次视觉调整不改变 Owner/Friend 规则、配额、邮箱验证码、真实航班查询范围、时区计算、数据隔离或同步协议。后续仍需以同一示例数据核对长文、空状态、跨时区、离线与失败状态，并在真实 iPhone 主屏幕 PWA 上回归。静态预览不是可用的产品功能。
